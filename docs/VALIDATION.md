With 36 cases, WTG P–Q produced 108 traces, built in **0.12 s**, and serialized to **0.36 MiB**. These are Python-side measurements; browser rendering and transfer are additional. With the one-case default, the same chart took **0.015 s** and produced 3 traces with about **17 KB** of Plotly JSON. That reduces the figure payload by about **97.6%** for the initial view. These timings cover Python-side work only, not Streamlit rendering or browser transfer. Session caches reuse inputs, parsed results, catalogues, mapping workbooks, violation summaries and figures; standalone mapping changes do not trigger CSV reparsing. The parse cache stores parsed channels without expanded CSV byte copies and retains one dataset per session. Range and loading-peak calculations stream through samples instead of building additional point-sized lists. The bounded plot cache includes a rendering revision so changed figure styles do not stay stale in a running session.
